# Chat Reader

Import a WhatsApp-style chat export (`.txt`) and read it as a conversation with day dividers, sender labels, and search. Parsing runs entirely in your browser — nothing is uploaded.

## Sample format

```text
24/02/2016, 12:43 pm - hesham: Hi
24/02/2016, 7:22 pm - Mohamed: Hi Back
```

## Develop

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm test` — parser unit tests
- `npm run preview` — preview production build
